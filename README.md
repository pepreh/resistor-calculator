# Resistor Color Code Calculator

## Description
A C++ command-line application that helps calculate resistor values using the standard color code system. This tool is essential for electronics students and engineers working with resistors. Users can convert between color codes and numerical values, view the color chart, and save information to files.

## Features
- Convert resistor colors to numerical values
- Convert numerical values to resistor colors
- View complete color code reference chart
- Save color code information to text file for future reference
- User-friendly menu interface
- Input validation for error handling

## Technologies Used
- C++
- File I/O (read/write operations)
- String manipulation
- Standard Library functions

## Resistor Color Code Reference
- Black = 0, Brown = 1, Red = 2, Orange = 3, Yellow = 4
- Green = 5, Blue = 6, Violet = 7, Grey = 8, White = 9
